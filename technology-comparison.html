What the data shows

  • The vanilla comparison favors Vaadin across all four model/effort combinations. Sol 6.1 and Astra 6 each pass all five Vaadin vanilla trials; their Angular results are 1/5 and 0/5.
  • Skills + MCP helps Luna on this task. Luna medium rises from 3/5 to 4/5, and Luna xhigh from 3/5 to 5/5. Sol and Astra stay at 5/5.
  • Higher effort does not increase Luna’s vanilla pass count here. Medium and xhigh both score 2/5 on Angular and 3/5 on Vaadin vanilla. With skills + MCP, xhigh scores 5/5 versus medium’s 4/5.
  • Vaadin’s higher pass rate also comes with a shorter average agent run. Vanilla averages 2m 39s versus Angular’s 3m 10s; skills + MCP averages 2m 31s.

Scope and interpretation

This is a partial report: the Codex portion is complete, while all 60 Claude Code trials are queued. Haiku 5.5, Sonnet 5 and Opus 5.5 are not included in these outcomes.

The tasks implement the same Petclinic veterinarian use case, but compare complete stacks: Angular + Quarkus + JPA versus Vaadin Flow + Spring Boot + jOOQ. Instructions, starter projects, dependencies and stack-specific verifier tests are part of the comparison. These results do not isolate the frontend framework alone.

There is one task pair and five repetitions per model/effort/configuration. A single result changes a model cell by 20 percentage points. Treat this as descriptive evidence for this benchmark task, rather than a general ranking of the technologies. The timing averages mix successful and unsuccessful solutions and do not measure application runtime performance. Failure causes have not been systematically diagnosed; Astra’s Angular failures are explained in the asterisk note below.
